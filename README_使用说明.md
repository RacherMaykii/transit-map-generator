# 轨道交通视觉设计工坊

这是一个完全本地运行、以轨道交通数据为基础的视觉设计与图片生产工具，目前包含线路站序图、出入口站名标识和配线图等功能。

## Beta 版本与反馈

本软件目前为 Beta 版本，可能存在未修复的 bug 或兼容性问题。新版本可能调整工程文件格式或数据结构，早期版本导出的 `.railcity` / `.railproj` 备份不一定能在新版本中正常打开，建议保留旧版本或旧备份。

发现 bug 或有建议，可在项目门户页脚点击「关于 / 关于本项目」查看作者的哔哩哔哩、抖音与 QQ 频道并反馈；「注意事项与免责声明」包含完整的使用须知与免责条款。

## 启动

双击 `启动本地工具.cmd`，等待浏览器自动打开即可。

如浏览器没有自动打开，请访问：`http://localhost:3000/`

启动脚本使用本地文件模式，默认项目“虚空城”继续读写 `data/` 下的 CSV，新建项目保存在 `data/projects/<项目ID>/` 下（新建时会先复制当前虚空城数据作为起点）。静态网站或不带 `?storage=http` 参数的页面使用浏览器模式：项目按城市隔离保存在浏览器 IndexedDB 中，不会写回原 CSV。

## 浏览器保存与备份

- 主页中的一个城市项目同时供线路站序图、出入口站名标识和配线图使用。
- 线路数据、显示设置、出入口设计和上传素材均按项目隔离；配线图自动保存也使用项目专属键。
- 出入口编辑器修改后点击“保存设计”；未保存时关闭或刷新页面会出现提示。
- 点击主页“导出项目”，可选择 `.railcity` 完整备份，或 `.railproj` 主要工程加 `.railassets` 资源包；导入同样二选一。只导入主要工程时缺失素材显示占位，稍后可单独补入资源包。
- 静态版可用 `npm run build:static` 生成到 `static-dist/`，部署后无需本地数据服务。

## 数据文件

- `data/lines.csv`：线路资料和各状态颜色。
- `data/stations.csv`：所有线路的站点资料；`is_open` 为逐线路站点开通标记，`1` 表示开通，`0` 表示未开通，留空按开通处理。
- `data/transfers.csv`：站点与换乘线路的对应关系。
- `data/layout.json`：128×128 画布布局和字体配置。
- `data/history/`：每次点击“保存 CSV”并成功写入后生成一个数据历史版本；恢复历史只替换线路、站点和换乘 CSV，不改变显示设置。

CSV 使用 UTF-8 BOM，可直接用 Excel 打开。建议正常编辑时使用网页，避免表格软件占用文件导致保存失败。

## 使用流程

1. 在父级页面选择“线路站序图生成”或“出入口站名标识生成”，打开“虚空城”项目。
2. 线路站序图编辑器中选择已有线路与运行方向，再拖动滑块选择当前站。
3. 出入口站名标识编辑器中选择线路和站点，替换对应站点背景并填写出口信息。
4. 出入口站名标识可导出一张 640×128 完整图，也可导出包含 5 张 128×128 切片的图片包。
5. 双击线路站序图预览中的站点或方向牌可以编辑对应资料。
4. 线路、站点或换乘修改使用顶部“保存 CSV”；样式和位置修改在“显示设置”中使用“保存显示设置”。两者互不覆盖。
5. 使用“站点检查”核对换乘、英文和重复记录，使用“开通统计”查看线路与站点状态。
6. 使用“导出线路图”“本站切片”或“导出图片包”生成 PNG。

快捷键：`Ctrl+S` 保存当前界面的内容、`Ctrl+Z` 撤销、`Ctrl+Y` 重做。

连续拖动文字、图形或滑块只记录为一个撤销步骤；同一输入框从开始编辑到离开输入框也只记录为一个步骤。

网页存在未保存修改时，关闭或刷新会显示浏览器确认提示。

## 配线图编辑器

打开配线图编辑器会弹出帮助教程，可点「跳过教程」跳过；之后点工具栏的“?”按钮可随时重新打开。顶部工具栏的「自动避让」默认开启：站名、图标与站台重叠时会被自动推开，避免相互遮挡；想手动微调时可关闭「自动避让」再拖动，或点「避让一次」手动整理。

1. 在项目门户进入“配线图编辑器”，新建或继续当前城市项目中的画布。
2. 可直接导入三类 CSV；预览确认后，新增站点进入待放置托盘，删除站点只标记源数据状态，不会删除图面对象。
3. 站点可拖到画布，或在前后相邻模块都存在时点击“插入相邻模块之间”。默认使用岛式站台模板并绑定源站点。
4. 导入图标 ZIP 或目录后，按 `stations.csv` 的 `icon` 文件名匹配；已有站点会自动附着匹配图标，也可改成独立位置。
5. 站名是独立附着标签，可在顶部选择仅中文、仅英文或中英双语。移动站点会保留标签和图标的相对偏移。
6. 选中两个以上模块，可建立十字、双岛、西班牙式、叠岛或出站换乘；双击换乘组合进入成员编辑。
7. “保存”写入当前城市项目；需要迁移或备份时，返回项目门户导出 `.railcity`，或拆分导出 `.railproj` 与 `.railassets`。
8. SVG/PNG 导出可选择整个画布或选中区域、透明背景、参考背景和 1x/2x/4x 分辨率。

R1 是 L7 与 L9 的运行交路映射。筛选 R1 会显示其成员线路，但不会重复创建物理轨道。

## 独立组件位置调整

“显示设置”中的实时预览固定在滚动区域顶部。切换到“本站”“下一站”“运行方向”或“线路标识”后，可以用滑块和数值框分别调整图形、标题、站名及说明文字的 X/Y 坐标；本站和下一站色条还可以分别调整宽度与高度。预览中的对应元素也可以直接拖动。所有坐标均以 128×128 矢量画布为基准，导出不同分辨率时会等比例缩放。

“站点与横条”中的“未开通站点按已过站配色”默认关闭。启用后，只把未开通站点、相邻横条和换乘标识的显示颜色替换为已过站配色，不修改站点的实际开通状态、当前位置或其他内容。双行英文的第一行与单行英文使用相同基准间距，第二行向下排列。

# Rail Transit Visual Design Studio / 轨道交通视觉设计工坊

可纯静态部署的轨道交通标识与配线图编辑器，包含线路站序图、出入口站名标识和 SVG 配线图工作台。浏览器模式使用 IndexedDB 保存城市项目；本地文件模式仍可直接维护 CSV。对外只使用城市级工程包：完整包为 `.railcity`，拆分包为 `.railproj` + `.railassets`。

## 主要功能

- 线路、站点、换乘 CSV 编辑、预览和校验
- 22 个配线模板，支持连续放置、双线自动连接和端口校验
- 轨道控制点、曲线、平面/断开/桥接交叉样式
- 多画布、树形图层、锁定、透明度、zIndex 与统一渲染顺序
- 背景大图预览、独立/附着文字、图标 ZIP/目录导入、站名语言模式和源站点绑定
- 十字、双岛、西班牙式、叠岛、出站换乘及多成员步行通道
- 字段级 CSV 增量变更、待放置托盘、相邻模块插入和物理站映射确认
- R1 运行交路通过 `ServicePattern` 映射到 L7/L9，不重复生成物理轨道
- SVG 与 PNG 1x/2x/4x 干净导出
- 图片包可选择 PNG/WebP/JPEG、128/256/512 px，并按最终 RGBA 像素去重
- 可生成严格 128×128 PNG 的“方块工坊地图画导入包”，清单保留重复用途的别名映射
- 配线图随城市项目自动保存，旧配线图工程结构继续兼容内部迁移
- 城市项目隔离、浏览器本地保存，以及完整或拆分式工程备份/迁移

## 技术栈

React 19、TypeScript、Vinext/Vite、SVG、Canvas、IndexedDB、fflate。项目采用 React 状态与纯逻辑模块实现原设计中的 store/domain 职责。

## 启动

Windows 可双击 `启动本地工具.cmd`。命令行方式：

```powershell
npm install
npm run data
npm run dev
```

打开 `http://127.0.0.1:3000/`。数据服务默认监听 `http://127.0.0.1:4175/`。

启动脚本会进入“本地文件模式”，默认项目“虚空城”读写 `data/` 中的 CSV，新建项目保存在 `data/projects/` 下。直接执行 `npm run dev` 并访问不带参数的首页则进入“浏览器模式”，线路数据、各编辑器设计和上传资源按项目隔离保存在 IndexedDB 中。

## 纯静态构建

```powershell
npm run build:static
```

生成结果位于 `static-dist/`，其中只有 HTML、JavaScript、CSS 和示例资源，不需要购买应用服务器或运行 `local-data-server.mjs`。把该目录部署到任意以站点根路径提供文件的静态托管平台即可。用户成果保存在当前浏览器；应在项目门户定期点击“导出项目”生成 `.railcity` 备份，换浏览器后用“导入项目”恢复。

## 验证

```powershell
npx tsc --noEmit
npm test
npm run lint
```

`npm test` 会先执行生产构建，再运行配线连接、画布/图层、CSV、运行交路和工程包测试。

## 方块工坊地图画包

在站序图页面点击“导出图片包”，开启“导出为方块工坊地图画导入包”。专用包只包含可制成单张 128×128 地图的站点与独立组件，不包含横向完整线路图；像素完全相同的图片只存一份，`manifest.json` 中的 `aliases` 记录它原本对应的方向、站台和状态。

## CSV 格式

可同时导入 `lines.csv`、`stations.csv`、`transfers.csv`，也可只更新其中一类；未选择的类型保留当前数据。示例位于 `public/sample-data/`。

- `lines.csv`：线路 ID、名称、编号、颜色和类型
- `stations.csv`：站点 ID、线路、顺序、名称、终点类型、贯通提示、开通状态和图标文件名
- `transfers.csv`：站点、目标线路、顺序、颜色覆盖和隐藏状态

导入预览会显示新增、删除、字段变化与引用/重复 ID 问题。CSV 是源数据；画布位置、轨道几何、图层和换乘图面类型只保存在工程中，不会擅自写回源 CSV。

## 配线图流程

1. 新建或选择画布，可设置尺寸、方向、背景和网格。
2. 导入 CSV，在“线路站点”中选择源站点。
3. 选择站型模板并在画布放置；相邻模块可自动生成上下行双线。
4. 使用连接工具或控制点调整轨道，创建换乘组合并整理图层。
5. 使用线路或运行交路筛选检查对象。
6. 点击“保存”写入当前城市项目，或导出 SVG/PNG；整个项目从门户统一导出。

## 工程文件

项目门户提供两种互斥的导入、导出方式：

- `.railcity`：完整城市工程，包含共享线路数据、三个编辑器的设计、配线图和用户上传素材，单文件即可恢复。
- `.railproj`：主要城市工程，保存所有设计、素材引用及缺失信息，但不内嵌用户素材。
- `.railassets`：与 `.railproj` 配套的用户资源包，只保存用户上传素材；程序内置公共素材不重复打包。

缺少 `.railassets` 时仍可打开 `.railproj`，缺失位置显示占位提示。之后在导入窗口仅选择资源包，即可按稳定引用补充到当前选中的项目。旧工程结构仍保留迁移代码，但不再作为编辑器中的另一套公开保存入口。

## 图层与换乘

对象只能放入叶子图层。最终绘制顺序为图层树顺序、对象 zIndex、创建顺序；父图层显隐、锁定和透明度会传递到后代。换乘组合使用独立的进出站关系和图面布局字段，支持十字、双岛、西班牙式、叠岛和出站换乘；双击组合可编辑成员，删除组合不会删除成员模块。

## 运行关系

`ServicePattern` 区分 normal、through 和 route。默认 R1 是由 L7 与 L9 组成的 route，筛选 R1 时显示两条成员线路，但 `renderAsIndependentTrack=false`，不会创建重复轨道。
